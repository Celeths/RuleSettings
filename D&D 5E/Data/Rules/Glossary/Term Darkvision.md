# Darkvision

If you have Darkvision, you can see in [[Term Dim Light]] within a specified range as if it were [[Term Bright Light]] and in [[Term Darkness]] within that range as if it were Dim Light. You discern colors in that Darkness only as shades of gray. _See also_ "Playing the Game" ("Exploration").
