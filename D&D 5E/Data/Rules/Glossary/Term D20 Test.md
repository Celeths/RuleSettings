# D20 Test

[[Term D20 Test]]s encompass the three main d20 rolls of the game: ability checks, attack rolls, and saving throws. If something in the game affects D20 Tests, it affects all three of these rolls. The GM determines whether a D20 Test is warranted in a given circumstance. _See also_ "Playing the Game" ("D20 Tests").
