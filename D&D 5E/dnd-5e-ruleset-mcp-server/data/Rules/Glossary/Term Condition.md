# Condition

A condition is a temporary game state. The definition of a condition says how it affects its recipient, and various rules define how to end a condition. This glossary defines these conditions:

- [[Term Blinded]]
- [[Term Charmed]]
- [[Term Deafened]]
- [[Term Exhaustion]]
- [[Term Frightened]]
- [[Term Grappled]]
- [[Term Incapacitated]]
- [[Term Invisible]]
- [[Term Paralyzed]]
- [[Term Petrified]]
- [[Term Poisoned]]
- [[Term Prone]]
- [[Term Restrained]]
- [[Term Stunned]]
- [[Term Unconscious]]

A condition doesn't stack with itself; a recipient either has a condition or doesn't. The [[Term Exhaustion]] condition is an exception to that rule.
