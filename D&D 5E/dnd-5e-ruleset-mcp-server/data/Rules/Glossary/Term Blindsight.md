# Blindsight

If you have Blindsight, you can see within a specific range without relying on physical sight. Within that range, you can see anything that isn't behind Total [[Term Cover]] even if you have the [[Term Blinded]] condition or are in [[Term Darkness]]. Moreover, in that range, you can see something that has the [[Term Invisible]] condition.
